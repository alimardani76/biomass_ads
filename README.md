# Biomass gasification determines MOF–zeolite ranking for hydrogen purification

**Reproduction package for the equilibrium screening framework of HKUST-1, Cu-TDPAT, and Zeolite 13X across 20,301 gasifier scenarios × 10 TSA thermal set-points × 3 adsorbents (609,030 scoring rows).**

This repository contains the released data, reproduction scripts, and reference artefacts supporting the manuscript:

> Z. Soltani, S. Abaei, M. Hoseinzadeh, F. Hooriabad Saboor, H. Alimardani, S. P. Amouzesh, M. Asgari.
> *Biomass gasification determines MOF–zeolite ranking for hydrogen purification: an interpretable regime-dependent screening.*

---

## What this repository does

Running the scripts here regenerates every data-derived figure and table in the paper:

- **Fig. 2** — Winner map: the gasifier operating plane partitioned into two adsorbent-preferred regions (Cu-TDPAT ≈ 23%, Zeolite 13X ≈ 77%)
- **Fig. 3** — Syngas composition maps under gasifier temperature and steam sweeps
- **Fig. 4** — Energy–productivity envelopes per adsorbent, per limiting impurity
- **Fig. 5** — Empirical cumulative productivity distributions
- **Fig. 6** — Exact TreeSHAP attribution over controllable variables
- **Fig. 7** — Inventory-scaled productivity
- **Fig. S15/S16** — XGBoost parity plots (random and gasifier-scenario-grouped splits)
- **Fig. S17** — Vacuum-swing robustness check
- **Fig. S18** — η/t_cycle robustness (Section S12)

Plus the artefacts referenced in the SI:
- XGBoost surrogate model files (`.json`) with held-out metrics (Table S11)
- TreeSHAP attribution table (Table S12)
- η/t_cycle robustness table (Table S15)

## Reproducing the paper

Assuming you have cloned the repo and installed dependencies, run from the repo root:

### 1. Validate the released data

```bash
python scripts/sanity_check.py
```

This confirms row counts, composition ranges, adsorbent-mass magnitudes, winner shares, and cached XGBoost R² values against the values reported in the paper. Takes ~5 seconds.

### 2. Regenerate all main-text and SI figures

```bash
python scripts/paper_pipeline.py
```

This is the workhorse. It runs six stages:

| Stage      | Output                                                     |
|------------|------------------------------------------------------------|
| `winner`   | Fig. 2 — winner map (also writes `winner_map_data.csv`)     |
| `compose`  | Fig. 3 — syngas composition maps                            |
| `envelope` | Fig. 4 — energy–productivity envelopes                      |
| `kde`      | Fig. 5 — empirical cumulative productivity distributions    |
| `ml`       | Fig. 6 + Figs. S15/S16 — XGBoost training + parity + SHAP   |
| `mass`     | Fig. 7 — inventory scaling                                  |

**First run:** ~2 minutes (XGBoost training dominates). Trained models and metrics are cached in `outputs/artifacts/`.

**Subsequent runs:** ~15 seconds. Cached models are reused unless you pass `--retrain`.

**Optional flags:**

```bash
# Retrain XGBoost from scratch, ignoring cache
python scripts/paper_pipeline.py --retrain

# Regenerate one figure only
python scripts/paper_pipeline.py --stage kde
python scripts/paper_pipeline.py --stage ml
```

### 3. Reproduce the η/t_cycle robustness analysis

```bash
python scripts/robustness_check.py
```

Generates:
- Table S15 data (`outputs/artifacts/robustness_check.csv`) — winner shares under 8 perturbations
- LaTeX table (`outputs/artifacts/robustness_table.tex`)
- Fig. S18 — winner maps under baseline + non-uniform η targets

Analytically confirms that the 22.86%/77.14% partition is exactly invariant to η and t_cycle scaling. Runs in ~10 seconds.

### 4. Reproduce the VSA winner map

```bash
python scripts/si_vsa_figure.py
```

Generates Fig. S17 (vacuum-swing winner map). Confirms that the ranking partition is preserved when the swing variable changes from temperature to pressure. Runs in ~10 seconds.

### Full clean reproduction from empty outputs

If you delete `outputs/` and rerun the four commands above, you get the same figures and artefacts as reported in the paper.

## Reviewer revision additions

The final [main manuscript and SI sources](manuscript/README.md) preserve the
Reviewer 1-3 revision, with one highlight switch per document. The new
[Fig. S19](outputs/figures/si/tsa_temperature/figS19_r1c5.pdf) is redrawn from
the existing source CSVs using:

```bash
python scripts/r1c5_minimal.py
```

The saved-score scope is 20,301 gasifier scenarios x 10 desorption set-points x
3 materials (609,030 rows), at fixed adsorption temperature 298 K and pressure
1 bar. The original, all ten fixed-temperature, and per-material optimized
comparisons each select 4,640 Cu-TDPAT, 15,661 Zeolite 13X and 0 HKUST-1
winners: zero changes across 203,010 fixed-temperature comparisons and zero
under optimization. Temperature affects productivity; only winner identity
was unchanged. Raw `T_adsorption(K)` is a legacy name for the swept
desorption/regeneration temperature and is preserved in the data and scripts.
No large temperature scenario-map CSV is needed for this redraw.

[Reference gasifier and X-103 evidence](data/revision_validation/README.md)
includes one original workbook, the component-split export and the traceable
four-gas comparison. The unchanged [independent audit script](scripts/r1c5_independent_audit.py)
and [short report](reports/R1C5_zero_change_audit.md) require extra local legacy
Excel files and analysis artifacts detailed in that provenance note; they are
not fully runnable from Git alone. See [executed revision checks](reports/revision_verification.md).

Limits remain: the adsorption/IAST cross-check is model-based, not experimental;
no independent matched-condition validation of production P-1 is available;
no rationale for its R7/R9 zero conversions is documented; the PI decision on
retaining the model-only 100% solid-carbon disappearance result is pending;
and the methane-zero convention limits physical interpretation of the winner
boundary. No numerical IAST comparison was added in this revision.

## Data

### `data/book1.csv`

Aspen HYSYS output for 20,301 upstream scenarios. Sweeps gasifier temperature (650–850 °C) and steam feed (50–150 kg/h) on a 201 × 101 grid. See `DATA_DICTIONARY.md` for column definitions.

### `data/TSA_DATA.csv`

Equilibrium TSA scoring atlas. 609,030 rows = 20,301 scenarios × 10 desorption set-points (`T_adsorption(K)` is the legacy column name) × 3 adsorbents. Each row gives adsorbent mass requirements (per limiting impurity), specific hydrogen productivity, and regeneration energy.

### `data/PSA_DATA.csv`

Vacuum-swing scoring variant used only for the robustness check. Adsorption pressure is fixed at 1 bar; desorption pressure is swept from 0.01 to 0.63 bar. The reported regeneration energy is an equilibrium lower bound — it does not include vacuum-pump or compressor work — and is therefore not compared with TSA energies in the manuscript.

### `data/hysys-rev-Final.xlsx`

The original HYSYS-derived workbook retained for provenance. Contains the same information as the CSVs plus the Excel formulas that produced the scoring outputs. Not required for reproduction but useful for anyone auditing the calculation chain.

### `data/CHECKSUMS.md`

SHA-256 checksums for verifying data integrity.

## Scope

This is an **equilibrium screening framework**. It applies a common working-capacity scoring rule to three benchmark adsorbents across a coupled process–material grid. It does not:

- Resolve cyclic breakthrough dynamics or mass transfer resistances
- Model column pressure drop or bed heat exchange
- Predict absolute product purity or hydrogen recovery
- Include vacuum-pump or compressor work in the PSA/VSA variant
- Extrapolate to unstudied adsorbents

These are downstream design decisions that require dynamic column models and are outside the scope of this release. The manuscript's Methods section §2 discusses this scope explicitly.

The XGBoost surrogate is used for feature attribution over the computed atlas via exact TreeSHAP, not as an independent predictor of unstudied adsorbents or conditions.

---

## What is not included

- **Earlier manuscript drafts** and exploratory development notebooks are intentionally excluded to keep this release focused on reproducibility of the published results.
- **HYSYS simulation files** (`.hsc`, `.bkp`) are not included. The workbook `hysys-rev-Final.xlsx` provides the exported gasifier scenario grid, which is what the scoring calculation actually uses.

## Reproducibility notes

- Random seeds are fixed (`random_state=442` for XGBoost, `default_rng(442)` for subsampling), so all outputs are deterministic across runs.
- XGBoost models are saved in portable JSON format and can be reloaded across XGBoost versions.
- Figure PNGs are rendered at 300 dpi; PDF versions can be added by editing the `savefig` calls in `paper_pipeline.py`.
- All scripts use `pathlib.Path` and resolve paths relative to the repo root, so they work from any working directory as long as they are invoked as `python scripts/<name>.py`.
